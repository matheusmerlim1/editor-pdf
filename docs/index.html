Editor de PDF

Um aplicativo de mesa em Python que abre um arquivo PDF, identifica o texto que existe dentro dele, permite reescrever esse texto e salvar tudo de volta em PDF — preservando posição, tamanho, cor e estilo de cada trecho.

O que ele faz

Identifica o texto

Percorre cada página e extrai todos os trechos de texto com a sua caixa, fonte, corpo e cor.

Edita na própria página

Clique sobre a palavra na página renderizada — ou escolha na lista lateral — e digite o texto novo.

Localiza e substitui

Troca uma palavra ou frase em uma página ou no documento inteiro de uma só vez.

Apaga trechos

Remove o texto do arquivo de verdade, e não com uma tarja por cima.

Desfaz até 25 vezes

Cada alteração guarda o estado anterior do documento inteiro; Ctrl+Z volta atrás.

Salva em PDF

O resultado é um PDF comum, que abre em qualquer leitor — inclusive por cima do arquivo original.

Como funciona

Um PDF não guarda parágrafos editáveis: ele guarda instruções de desenho que colocam grupos de caracteres em coordenadas da página. Editar, então, é um processo de três passos — e nessa ordem, porque o texto novo só pode ser escrito depois que o antigo sai.

  1. 1

    Leitura

    O documento é lido trecho a trecho (span). Cada trecho traz o texto, a caixa que ele ocupa, a linha-base onde começa, a fonte, o corpo em pontos e a cor. 

    # para cada span da página
dados = pagina.get_text("dict")
  2. 2

    Substituição

    A área do trecho antigo é marcada e apagada por uma redação — que remove só os caracteres, deixando imagens e desenhos vetoriais intactos. Em seguida o texto novo é escrito exatamente sobre a mesma linha-base, com o corpo e a cor originais. 

    pagina.add_redact_annot(caixa)
pagina.apply_redactions(images=NONE, graphics=NONE)
pagina.insert_text(origem, texto_novo, fontname, fontsize, color)
  3. 3

    Gravação

    O documento é gravado novamente, com limpeza dos objetos que ficaram sem uso e compressão dos fluxos. 

    doc.save(destino, garbage=4, deflate=True)

Sobre as fontes

A fonte original nem sempre vem embutida no arquivo. Por isso o texto novo é reescrito com a fonte base-14 equivalente — as três famílias que todo leitor de PDF é obrigado a ter — escolhida pelo nome e pelos atributos da fonte original.

Instalação

Executável pronto

Baixe o EditorPDF.exe na página de releases e execute com dois cliques. É portátil: não instala nada e não exige Python na máquina. Também dá para arrastar um PDF sobre o ícone para abri-lo direto.

Baixar a versão mais recente

A partir do código-fonte

Requer Python 3.9 ou superior.

git clone https://github.com/SEU-USUARIO/editor-pdf.git
cd editor-pdf
pip install -r requirements.txt
python editor_pdf.py

Para gerar o executável você mesmo, rode build_exe.bat.

Limitações

  • PDFs digitalizados são só imagem: não há texto para identificar. Seria preciso reconhecimento óptico de caracteres (OCR) — o programa avisa quando isso acontece.
  • Como o texto é reescrito com as fontes base-14, uma fonte muito característica do documento não é reproduzida com exatidão.
  • A edição é feita por trecho, e não por parágrafo: um texto bem maior que o original não reorganiza a quebra de linha sozinho — apenas o corpo da fonte é reduzido para caber.
  • Alfabetos fora do conjunto latino-1 (grego, cirílico) não são cobertos pelas fontes base-14. Travessões e aspas curvas são convertidos automaticamente.
